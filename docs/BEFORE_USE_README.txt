GameOptimizer 使用说明 (v1.1.0)
======================================

用途：Windows 端 8 款热门游戏（三角洲行动/英雄联盟/CS2/绝地求生/无畏契约/
Apex Legends/Dota 2/守望先锋2）一键优化工具（硬件无感适配）。
安全约束：仅用官方 WinAPI 改进程属性；无注入、无内核 Hook；优先级上限 HIGH；
          每次应用自动快照（持久化，跨进程可回滚）；电源切换默认关闭（功能本身免费）。

【0】自检（复制到目标机后先跑一次）
      双击 自检.cmd —— 机制自检输出 PASS（真实进程的优先级/亲和性 设置+恢复），
      再打印硬件指纹与预设。

【1】图形界面（推荐）
      gopt_gui.exe —— 界面为「顶部标题栏 · 左侧五页导航 · 内容区 · 底部日志 + 状态栏」，
      右上角可切换 中文/English；窗口缩放或系统缩放（125%/150%）时布局自动重排。
      左侧五页：
        总览     硬件卡（CPU/核数/GPU/内存）+ 实时卡（CPU、内存大号数字与进度条）+
                  48 秒实时曲线；左下动作区：「一键性能优化」（后台执行，界面不卡顿）、
                  「开机自启动」勾选、「回滚最近一次优化」、「诊断 / 关于」；
                  右下「优化历史」= 最近快照列表（最新在前，★ 标记回滚目标），
                  每 5 秒只读刷新，双击某一条可查看该项的条目明细
        游戏优化 选择游戏 → 右侧显示该游戏按硬件降级后的预设摘要（优先级/CPU 核数/
                  工作集/电源）；可填「代启动路径 + 启动参数」让工具代启动，并用
                  三个开关控制 电源/帧延迟/工作集；「保存游戏设置」持久化到本机；
                  「应用优化」后台执行并显示进度与每步明细；「回滚」撤销最近一次
        系统调优 高性能档/平衡档/恢复调优（电源 + 处理器档 + 调度优先级，需管理员），
                  同时显示当前电源方案与按硬件的推荐档位；
                  「清理临时文件」= 二次确认（首次点击进入 5 秒确认态，再点一次才执行；
                  24 小时内修改过的文件一律保留）
        进程     查看运行中的支持游戏：优先级 + 实时 CPU 占用 + 内存 MB（按 CPU% 降序）；
                  「提升优先级 / 恢复正常」，双击某一行同样等于「提升优先级」
        启动项   开机启动项 启用/禁用（禁用 = 改名保留并备份，可一键还原）；
                  选中项会显示完整命令行
      关闭窗口 = 最小化到系统托盘（后台看门狗继续）；双击图标恢复，
      右键菜单可退出、也可直接「清理临时文件」；优化完成时托盘气泡提示。
      一键优化/应用优化进行中，内容区会叠加「优化流程」面板（步骤状态行 + 旋转指示，
      结束后自动隐藏），底部日志保留完整明细。
      界面配色由统一设计令牌绘制，跟随系统浅色/深色主题；每个按钮与列表操作都有
      状态行或日志回执（不会"点了没反应"）。

【2】命令行
      gopt_cli --version / status / fingerprint
      gopt_cli report [--out <文件路径>]        诊断报告（一条命令导出全部状态；UTF-8 无 BOM）
      gopt_cli apply cs2                       游戏运行中 attach
      gopt_cli apply cs2 --dry-run             只读预览将应用的优化项（不修改）
      gopt_cli apply cs2 --game-exe "<路径>"    代启动
      gopt_cli optimize [游戏|system]          一键：优化全部运行中的支持游戏
      gopt_cli rollback / rollback-all         回滚（跨进程）
      gopt_cli savepoints [list|show <n>]      只读查看快照历史 / 第 n 条明细
      gopt_cli tune [high|balanced|restore]    系统调优（电源/处理器档/调度优先级）
      gopt_cli startup list|disable|enable|restore   启动项管理
      gopt_cli prio <pid> high|above|normal|below|idle  进程优先级
      gopt_cli watch [秒数] [--top [N]]        实时监视；--top 显示进程热点榜
      gopt_cli game <游戏> [--exe <路径>] [--args "<参数>"]  查看/保存代启动配置
      gopt_cli clean                           清理临时文件（24 小时内保留）
      gopt_cli list                            运行中支持游戏概览
      gopt_cli license status / activate <码>  授权（所有功能免费，授权可选）

【3】授权（所有功能免费；仅机器指纹用于潜在企业/捐赠场景）
      所有优化项（优先级/亲和性/工作集/电源/帧延迟）免费开放，无任何门控。
      如需绑定授权，用 `gopt_cli fingerprint` 获取本机指纹哈希。

注意：64 位 Windows；无注入、无内核 Hook，可放心用于带反作弊的游戏。
若 Windows 弹 SmartScreen，选"更多信息 → 仍要运行"。
