# GameOptimizer 商业化方案（草案 v0.1）

> 前提：产品需先完成编译验证并打磨为可发布版本。本文给出定价、分发、授权与合规的
> 推荐路线，供讨论后细化。

## 1. 产品定位与卖点

- 一句话：**面向三款热门竞技游戏的"硬件无感"一键优化工具**（三角洲行动 / 英雄联盟 / CS2）
- 差异化卖点：
  1. **硬件无感**：自动识别 CPU/GPU/内存，无需手动配置
  2. **安全**：只用官方 WinAPI，无注入、无内核 Hook（对反作弊游戏是硬性信任点）
  3. **一键回滚**：每次修改都有快照，秒级恢复，无残留
  4. **降级哲学**：任何不支持的特性自动跳过，绝不硬来

## 2. 定价策略（建议：免费基础 + Pro 买断）

| 版本 | 功能 | 建议价格 |
|---|---|---|
| 免费版 | 三角洲/LoL 基础预设（优先级+亲和性）、状态查看、回滚 | ¥0 |
| Pro（买断） | 全部游戏全部特性：CS2 物理核绑定、电源方案切换、驱动级帧延迟(NVAPI/ADL)、看门狗自动回滚、未来新游戏预设 | ¥39（首发 ¥29） |
| Pro（订阅，可选） | 同上 + 云端预设同步 + 新游戏抢先适配 | ¥6/月 |

参考锚点：Process Lasso Pro ≈ $30 买断（功能更广但无游戏预设）；同类"游戏加速"工具
多为免费或订阅制。**¥29-39 买断**在中文游戏玩家中属冲动可接受区间。

## 3. 分发渠道（按优先级）

1. **官网直售 + 授权码**（首选，利润 100%）
   - 需一个简单的网站 + 支付（微信/支付宝/Stripe）
   - 授权：注册码文件 + 本机硬件指纹绑定（SMBIOS 主板序列号 + HardwareProfile 摘要）
   - 可由我协助搭建静态官网 + 生成/校验授权码的离线工具
2. **itch.io**（低门槛、手续费 10% 可选、支持国内支付较麻烦）——作为英文市场补充
3. **Steam**（$100 上架费；工具类过审难度中等；如果走这条路需 Steamworks 集成）
4. **国内商店**（需软件著作权登记，流程 1-2 个月；上架腾讯电脑管家/360 等）

**不建议首发**：订阅制 SaaS（游戏优化不需要云服务，运维成本高）、App Store（Windows
工具无此渠道）。

## 4. 授权与防破解（v1 务实做法）

- 不做强加密防破解（工具类破解成本低，投入不划算）
- 做法：**注册码文件**（含签名）+ 首次激活绑定机器指纹；免费版无授权限制
- 目标：挡住"随手转发"级传播即可；重点放在让 Pro 值回票价

## 5. 合规风险（必须写进产品文档）

| 风险 | 等级 | 对策 |
|---|---|---|
| 反作弊误判（三角洲 ACE / CS2 VAC / LOL 反作弊） | 中 | 只用官方 API 改进程属性（与 Process Lasso 同类操作）；**严禁注入/Hook 写入产品红线**；官网明示安全边界 |
| 游戏 ToS 禁止第三方修改 | 中 | 免责声明 + 用户自行确认；提供"仅代启动、不附加任何修改"的纯净模式 |
| 电源方案切换权限 | 低 | 默认关闭，仅 Pro + 管理员可用 |
| 商标/素材（游戏名、LOGO） | 低 | 官网与产品内使用文字名称，不用官方 LOGO 与美术素材 |
| 软件著作权 | — | 国内上架前办理（可代办，费用约数百元） |

## 6. 收入现实预期（保守测算）

- 目标用户：中文区三款游戏活跃玩家（数百万级），工具类转化率通常 0.1%~1%
- 10 万曝光 → 500~1000 购买 × ¥35 ≈ **¥1.7万~3.5万**（首发期）
- 长期靠：版本更新口碑 + 新增游戏预设 + 订阅选项
- **结论**：这是"小而美"副业级产品，月入数千到数万，不是暴利项目；适合作为
  开发者个人品牌与后续产品的入口
